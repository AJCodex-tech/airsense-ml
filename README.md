# AirSense: Machine Learning-Based Air Quality Analyzer

AirSense predicts an Air Quality Index (AQI), classifies pollution severity, and discovers recurring environmental patterns. It is designed as a practical, syllabus-aligned machine-learning project that you can run locally and extend with public air-quality data.

## What it demonstrates

| ML area | AirSense implementation |
| --- | --- |
| AQI prediction | PM2.5-only linear-regression baseline and multiple linear regression |
| Pollution classification | Gaussian Naive Bayes, Logistic Regression, entropy Decision Tree (ID3-style), Linear SVM, RBF SVM, Perceptron, and MLP |
| Unsupervised learning | K-Means, Agglomerative Clustering, Gaussian Mixture Model (EM) |
| Dimensionality reduction | PCA with explained-variance reporting |
| Evaluation | MAE, RMSE, R², accuracy, precision, recall, F1, and one-vs-rest ROC-AUC |
| Data processing | Missing-value imputation, standardization, time features, and location encoding |

## Quick start

Use Python 3.10+ and create a virtual environment if possible.

```powershell
python -m pip install -r requirements.txt
python main.py --action all
```

That command generates 2,000 synthetic sensor observations, trains all models, saves the best classifier and AQI regressor, writes a metrics report, and produces visualizations.

To launch the interactive interface after training:

```powershell
streamlit run src/dashboard.py
```

## Commands

```powershell
# Generate a different-sized demo dataset
python -m src.generate_data --rows 5000 --output data/air_quality_demo.csv

# Train using the generated or your own data
python -m src.train --data data/air_quality_demo.csv

# Make a command-line prediction from sensor values
python -m src.predict --pm25 86 --pm10 145 --no2 72 --so2 18 --co 1.4 --o3 52 --temperature 30 --humidity 58 --wind-speed 2.8 --location "New Delhi"
```

## Expected CSV schema

For real data, provide the following columns. `timestamp`, `aqi`, and `pollution_level` may be produced during preprocessing when appropriate, but a real official AQI target is recommended for final results.

```text
timestamp,location,pm25,pm10,no2,so2,co,o3,temperature,humidity,wind_speed,aqi,pollution_level
```

Pollution levels are `Good` (0–50), `Moderate` (51–100), `Unhealthy` (101–200), and `Hazardous` (201+). The included generator uses a clearly labelled AQI proxy for demonstration; it is not an official regulatory AQI calculation. For a submission, replace it with an official dataset and document the AQI standard used.

## Outputs

After training, inspect:

- `reports/classification_metrics.csv` — comparison of all supervised classifiers.
- `reports/regression_metrics.csv` — PM2.5 baseline versus multiple-regression AQI model.
- `reports/cluster_assignments.csv` — K-Means, hierarchical, and EM cluster labels.
- `reports/project_summary.md` — concise run summary and PCA variance.
- `plots/` — regression fit, model comparison, PCA clusters, dendrogram, AQI by location, and class distribution.

## Academic notes

- The entropy Decision Tree is an ID3-style implementation available in scikit-learn; continuous features are split using the library's optimized thresholds.
- Gaussian Naive Bayes estimates per-class Gaussian parameters with maximum likelihood and returns Bayesian posterior probabilities.
- GMM uses expectation-maximization (EM) to fit probabilistic clusters.
- A decision-function score is used for ROC-AUC when a model does not expose probabilities; it is still a ranking-based ROC measure.
- The train/test split is stratified for pollution classification, while clustering uses all available observations because it is unsupervised.
